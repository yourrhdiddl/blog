# 테스트 보고서 · AIPM 복습 노트 「AI 글 정리 도우미」

> **이 문서의 목적:** AI 제안 기능과 관련 기능이 [PRD v0.7](PRD_AIPM복습노트_AI글정리도우미_v0.7_하늘_20261124.md)의 요구대로 동작하는지 시험한 방법과 결과를 기록하고, 아직 시험하지 못한 부분과 작업 중 생긴 사고를 숨기지 않고 적는다.

**v0.1 → v0.2 변경:** 실제 Gemini 실행·수락 결과 추가, Firestore 규칙 일부 확인, v3.1·v3.2 기능(수정·휴지통·임시저장·상세 카드) 시험 추가, 시험 파일 소실 사고 기록.

## 3. 실서비스 시험 결과 (2026-11-24)
| 항목 | 결과 |
|---|---|
| Actions 실행 | `ai-suggest` 수동 실행 4회(기준값 측정 포함)를 마쳤다 |
| 제안 생성(첫 실행) | 공개 글 3편 중 **2편 성공, 1편 실패**(사유 "요약이 너무 김", 요약 120자 초과 검사). 성공 건의 요약은 102자·106자 |

| 사용자 반영 | 성공한 2편을 하늘이 수락. 두 글 모두 요약·제목·태그 `accepted` → 수락률 요약·제목 **4/4(100%)**, 태그 포함 6/6 |
| 기준값 V1 | 전체 5편 중 요약 자동 대체 3편(60%), 태그 빈 글 3편(60%) |
| Firestore 규칙 | 관리자 **update 허용 확인**(제안 반영 2건, 글 수정 저장 1건, 휴지통 이동·복구 1건). **delete 허용 여부 미확인**. 비관리자(시크릿 창)의 수정 거부도 **미시험** |
| 글 수정(F6) | 실제 사이트에서 글 1편을 수정 저장해 AI 요청(`pending`)이 걸리는 것을 확인 |
| 휴지통(F7) | 시험용 글 1편으로 이동 → 목록에서 사라지고 휴지통 탭에 "휴지통 (1)" 표시 → 복구하면 나만보기로 원복. **영구삭제·15일 자동삭제는 미시험** |

**수락률 해석:** 표본이 글 2편이고 전부 수락했으며 글 3편이 Claude가 쓴 초안이라 **통계 검증이 아니다.** 변별력이 없어 "제안이 좋았다"는 결론을 내리지 않는다. 실제 복습 글 10편 이상에서 재측정한다. 재실행 글의 제안은 하늘의 수락·무시를 기다리는 중이라 집계에 넣지 않았다.
**배치 성공률:** 첫 실행 2/3(67%), 누적 요청 3/4(75%). 목표 95%에 **미달**이다.

## 5. 시험하지 못한 것과 한계, 사고 기록
- **시험 파일 소실(사고):** v3.1에서 만든 화면 시험 67건(수정·휴지통·가독성 등, UI-16~67)이 담긴 `ui-check.mjs`를 작업 중 구버전 파일로 **덮어써 잃었다.** 위 23건은 구버전(15건)을 복원해 가짜 Firestore에 삭제 함수를 보강하고 새 시험을 더한 것이다. 수정·휴지통·읽기 화면 회귀 시험 일부가 비어 있어 **실제 사이트 수동 확인(3장)으로만 부분 보완**했다. 이 파일은 저장소에도 없다.
- **다크 모드:** 시험 도구가 색 모드 전환을 지원하지 않아 이번에 자동 검증하지 못했다(v3.1 때는 라이트·다크 각 67/67이었으나 기록은 이 문서가 아닌 대화에만 있다).
- **실사진·실기기:** 가짜 이미지로 시험했다. 하늘님이 실제 사진을 넣은 글 상세 화면을 직접 확인하기 전이다.
- **영구삭제와 자동삭제:** 규칙 delete 허용이 미확인이라 시험하지 않았다. 자동삭제는 관리자가 사이트를 열 때만 실행된다.
- **비관리자 쓰기 거부:** 시크릿 창에서 수정이 거부되는지 시험하지 않았다.
- **요약 80자 프롬프트:** 재실행 1건뿐이다. 재현성은 모른다.
- **캡처 이미지:** v0.1의 캡처 6장은 `docs/img`에 아직 올라가지 않았다(하늘님 업로드 필요). 이번 보고서에는 새 캡처를 넣지 않았다.
