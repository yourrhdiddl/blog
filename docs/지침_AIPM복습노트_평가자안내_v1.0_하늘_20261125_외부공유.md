# 평가자 안내 · AIPM 복습 노트 「AI 글 정리 도우미」

> **외부공유용.** 비밀번호는 이 문서에 적지 않았습니다. 담당자(하늘)가 따로 전달합니다. 소요 시간은 약 10분입니다.

**문서 버전** v1.0 · **작성일** 2026-11-25 · **담당** 하늘 · 사이트: https://yourrhdiddl.github.io/blog/ · 평가 기간: 2026-12-02까지(그날 평가자 계정은 삭제됩니다)

## 1. 이 기능이 하는 일

글을 올리면 AI가 **요약·제목 후보 3개·태그 3~5개를 제안**합니다. 제안은 내가 눌러야만 글에 반영되고, 누르기 전에는 글이 그대로입니다. 목적은 글마다 요약·제목·태그를 직접 쓰는 번거로움을 줄이는 것입니다.

## 2. 로그인 (1분)

1. 사이트에 접속해 로그인 화면(`#/login`)을 엽니다.
2. 구글 로그인 버튼 아래의 작은 글씨 **「평가자 로그인」**을 누릅니다.
3. 이메일 `evaluator@aipm-review.test`와, 따로 받은 비밀번호를 입력합니다.
4. 입력이 틀리면 안내 문구가 나옵니다. 다시 입력하면 됩니다.

## 3. 해 볼 것

**A. AI 제안 확인하고 반영·무시 누르기 (필수, 약 5분)**

1. 글 목록에서 제목이 **「[테스트용] 임시 제목」**인 글 하나를 엽니다(같은 제목의 글이 여러 개입니다. 아무거나 하나를 고르면 됩니다).
2. 글 아래의 **AI 제안 카드**에서 요약·제목 후보·태그를 읽습니다.
3. 항목을 골라 **반영** 또는 **무시**를 누릅니다. 반영하면 고른 항목만 글에 바뀌어 들어갑니다.

**B. 내 글을 새로 저장하기 (선택, 약 3분)**

1. 글쓰기 화면에서 제목과 본문을 쓰고 「AI 제안 받기」를 켠 채 공개로 저장합니다(평가자는 공개 글만 저장할 수 있습니다).
2. AI 제안은 담당자가 AI 실행을 눌러야 도착합니다. 저장하자마자 자동으로 오지 않습니다. 평가자 화면에는 담당자가 실행해 드린다는 안내가 나옵니다.
3. 이 흐름은 담당자가 실제 화면에서 아직 확인하지 못한 부분입니다. 안 되면 담당자에게 알려 주세요.

## 4. 알아 둘 것

- **권한:** 평가자는 자기가 쓴 글만 만들고 고칠 수 있습니다. 남의 글 수정과 모든 삭제·휴지통은 안 됩니다.
- **소진:** 반영 또는 무시를 누르면 그 글의 제안 카드는 사라지고 같은 글에서 다시 볼 수 없습니다. 체험용 글은 `[테스트용] 임시 제목` 10개를 포함해 여러 개 준비돼 있지만 한정되어 있으니 필요한 만큼만 눌러 주세요.
- **AI는 틀릴 수 있습니다.** 그래서 자동으로 반영하지 않습니다. 제안이 엉뚱하면 무시를 누르면 됩니다.
- **한도:** 하루 AI 호출은 20건까지입니다.
- **개인정보:** 개인정보나 비밀번호를 글에 쓰지 마세요. 평가자가 저장한 글은 누구나 볼 수 있습니다.

## 5. 문의
