## 3. 파일명 규칙
형식: `종류_프로젝트_세부제목_v버전_담당자_작성일.md` (밑줄로 구분, 작성일은 YYYYMMDD)

| 칸 | 규칙 | 예 |
|---|---|---|
| 종류 | PRD, 결정로그, 실패로그, 테스트보고서, 지침 중 하나 | PRD |
| 프로젝트 | AIPM복습노트 | AIPM복습노트 |
| 세부제목 | 띄어쓰기 없이 붙여 씀 | AI글정리도우미 |
| 버전 | 있을 때만 v숫자.숫자 | v0.6 |
| 담당자 | 있을 때만 | 하늘 |
| 작성일 | YYYYMMDD | 20261124 |
| 외부 공유용 | 파일명 끝에 _외부공유 추가 | …_20261124_외부공유.md |

- 에이전트 지침(CLAUDE.md, README.md)은 docs 밖 저장소 최상위에 두고, 그 외 모든 문서는 docs 폴더에 둡니다.
- 버전이 오르면 새 파일을 만들고 이전 파일은 지우지 않습니다. 새 버전을 올릴 때마다 위 2장 표에 한 줄을 추가합니다.
