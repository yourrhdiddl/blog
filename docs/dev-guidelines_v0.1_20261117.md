# AIPM 복습 노트 · 개발 지침 v0.1 (시스템 프롬프트용)

> AI에게 작업을 시킬 때 가장 먼저 읽히는 문서입니다. 바뀌면 버전을 올립니다. 마지막 수정: 2026.11.17

## 1. 프로젝트
- 이름: AIPM 복습 노트 (수업 복습을 기록하는 개인 블로그)
- 필수 기능: 글 목록, 글 상세, 글쓰기, 관리자 로그인. 로그인한 관리자만 글 쓰기·수정·삭제. 글은 공개와 나만보기로 구분.
- 현재 단계: 1차(첫 화면 배포) 완료, 2차(5개 화면 시안) 완료. 다음은 3차(로그인 → 글쓰기 → 목록에 내 글 표시).

## 2. 지켜야 할 규칙
1. 모든 글꼴은 Pretendard. 본문 17px 이상, 줄 간격 1.8, `word-break: keep-all`.
2. 디자인은 `docs/design-system.md`의 색, 간격, 모서리 값만 쓴다. 새 값이 필요하면 먼저 의사결정 문서에 적는다.
3. 비밀값(API 키, 비밀번호, 토큰)은 코드와 대화창에 쓰지 않는다. `.env`에만 두고 `.gitignore`로 제외한다. 확인할 때도 값을 출력하지 않는다.
4. 비공개 글은 화면에서 숨기는 것만으로는 부족하다. 데이터베이스 보안 규칙으로 막는다.
5. 시안(아티팩트)과 실제 배포 사이트를 혼동하지 않는다. 시안은 저장되지 않는다.
6. 결정은 `docs/decisions_*.md`에, 실패는 주제별 파일로 `docs/failure-log_*.md`에 남긴다.

## 3. 기술 선택 (강의 기준)
- 현재: 정적 HTML 한 파일(`index.html`) + 깃헙 Pages 배포.
- 3차 이후: 파이어베이스(Authentication, Firestore, Hosting). 설정값은 보안 규칙으로 지키고, 클로드·오픈AI 키는 화면 코드에 절대 넣지 않는다.

## 4. 소통과 파일
- 한국어, 시간은 한국시간(KST), 금액은 원화.
- 파일명: `프로젝트_세부제목_버전_(담당자)_날짜`. 내부용은 사내 문서, 외부 공유용은 파일명에 외부공유명을 붙인다.
- 완료한 산출물은 구글 드라이브 내부용 폴더에 올린다.
