# 실패 로그 · 붙여넣기 후 옛 내용이 남음 (2026.11.17)

- **증상:** 깃헙 웹 편집기에 새 `index.html`을 붙여넣고 커밋했더니 파일이 311줄이 아니라 443줄. 뒤에 v0.1 내용이 그대로 붙어 있었음.
- **원인:** "전체 선택" 없이 붙여넣어서 기존 내용이 지워지지 않고 앞에 끼워짐.
- **해결:** 편집기에서 `Ctrl+End` 후 `Shift+↑`로 남은 132줄을 선택해 삭제하고 다시 커밋. 해시 일치로 확인.
- **재발 방지:** 덮어쓸 때는 실제 키보드 `Ctrl+A`로 전체 선택 후 붙여넣고, 커밋 후 반드시 파일 길이나 해시로 검증한다.
