# 실패 로그 · 글쓰기 편집기 (3차)

> 서식·이미지 편집기를 만들고 시험하며 막힌 일.

## 2026.11.17 · 글자를 선택한 채 이미지를 넣으면 글자가 사라짐
- **증상:** 글자를 전부 선택(Ctrl+A)한 뒤 이미지 버튼을 누르면 선택한 글자가 이미지로 바뀜. 실제 사이트 시험에서 발견.
- **원인:** `insertImage` 명령이 선택 영역을 덮어씀.
- **해결:** 이미지를 넣기 직전에 선택을 끝으로 접는다(`getSelection().collapseToEnd()`). v0.6.1.

## 2026.11.17 · 크기를 바꾸면 앞서 정한 색 서식이 풀리거나 적용이 안 됨
- **증상:** 굵게→색→크기 순서로 누르면 마지막 크기가 적용되지 않음(가짜 로그인 시험).
- **원인:** 이전에 저장해 둔 선택 범위가 서식 적용 뒤 낡아서, 새 선택 대신 낡은 범위가 복원됨.
- **해결:** 에디터 안에 현재 선택이 있으면 그것을 쓰고, 없을 때만 저장한 범위를 복원.

## 2026.11.17 · 긴 코드를 브라우저로 옮길 때 복사 오류
- **증상:** 압축·base64로 바꾼 코드를 직접 옮겨 적었더니 조각마다 검증 값이 틀림.
- **해결:** 읽을 수 있는 글자로 된 변경 조각만 옮기고, 조각마다 해시로 검증한 뒤 합쳐 최종 해시를 확인. 이후에도 같은 방식 사용.
- **교훈:** 직접 옮겨 적는 데이터는 사람이 읽을 수 있는 형태가 오류가 적다. 항상 해시로 확인.

## 2026.11.17 · 이미지 용량 한도
- **내용:** 글 한 편이 Firestore 문서 한도(약 1MB)를 넘으면 저장이 안 됨. 코드에서 950KB 초과 시 "글이 너무 커요" 안내. 한도 근처 시험은 아직 하지 않음(4차 전 확인 필요).
