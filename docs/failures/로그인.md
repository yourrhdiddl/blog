# 실패 로그 · 로그인 (3차)

> 3차를 진행하며 막힌 일을 여기에 적습니다.

## 2026.11.17 · 샌드박스에서 Firebase 스크립트 주소가 막혀 있음
- **증상:** 작업 환경에서 `gstatic.com`(Firebase 라이브러리 주소)이 403이라 실제 로그인을 시험할 수 없음.
- **해결:** 라이브러리를 가짜(stub)로 바꿔 화면 흐름만 시험 → 로그인, 글쓰기, 목록 표시, 로그아웃 시 나만보기 글 숨김 확인. 진짜 로그인은 배포 후 브라우저에서 확인.
- **한계:** 보안 규칙은 이 시험으로 검증되지 않음. 시크릿 창에서 나만보기 글이 열리지 않는지 직접 확인해야 함.

## 2026.11.17 · Firestore 위치 선택 목록이 열리지 않음
- **증상:** 데이터베이스 만들기 화면에서 위치 드롭다운을 눌러도 목록이 보이지 않음.
- **원인(추정):** 브라우저 창이 숨김 상태라서 목록이 그려지지 않음.
- **해결:** 브라우저 창을 다시 보이게 한 뒤 직접 선택.

## 2026.11.17 · 관리자 UID를 코드에 넣다가 파일 맨 앞에 잘못 들어감
- **증상:** 깃헙 웹 편집기에서 `ADMIN_UID` 따옴표 사이에 값을 넣으려 했는데, 클릭이 실패한 상태에서 입력해 파일 맨 앞(`<!DOCTYPE html>` 앞)에 값이 들어감.
- **해결:** 저장하기 전에 편집기를 새로 열어 변경을 버리고, 줄 위치를 계산해 클릭한 뒤 커서 앞뒤 글자를 확인하고 입력. 저장 뒤 해시로 확인.
- **교훈:** 클릭 전에 새 스크린샷을 찍고, 입력 전에 커서 위치를 읽어서 확인한다.

## 2026.11.17 · Firestore 위치가 서울이 아니라 nam5(미국)
- **증상:** 결정 문서에는 서울로 적었으나 콘솔 확인 결과 `nam5`.
- **원인:** 위치 선택 목록이 열리지 않아 도움을 받아 마무리했고, 최종 선택값을 확인하지 않고 기록함.
- **해결:** 위치는 만든 뒤 바꿀 수 없어 그대로 사용. 결정 #17에 정정. 
- **교훈:** 설정값은 만든 뒤 화면에서 읽어서 기록한다.
