# 실패 로그 · 글쓰기 화면에서 공개 설정 버튼이 안 눌림 (2026.11.17)

- **증상:** 글쓰기 화면의 "나만보기" 라디오 버튼을 눌러도 선택이 안 바뀜.
- **원인:** 글 수정용 폼에 `data-id=""` 속성을 붙였는데, 화면 전체의 클릭 처리기가 `data-id`가 있는 요소를 "글 링크"로 보고 기본 동작을 막아 버림.
- **해결:** 폼의 속성 이름을 `data-pid`로 바꿈.
- **재발 방지:** 한 화면의 클릭 처리기가 쓰는 속성 이름(`data-id`, `data-go` 등)은 폼과 입력창에 다시 쓰지 않는다.
