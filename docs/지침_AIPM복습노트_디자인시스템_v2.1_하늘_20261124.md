# AIPM 복습 노트 · 디자인 시스템 (v2.1 · 흑백 에디토리얼 + 사진 갤러리)

> 목적: 블로그 화면의 색·글꼴·모양 규칙을 한곳에 적어 두어, 누가 고쳐도 같은 모양이 나오게 한다.
> 기준: 복습노트 v11 문서(AIPM복습노트_20261026-20261120_1-4주차전체정리_웹_v11.html)의 CSS. 결정 #37.
> 옛 파스텔 규칙(v0.4, 2026-11-17)은 이 문서 맨 아래 "이전 버전"에 요약만 남긴다.

## 원칙
1. 색은 흑백 + 회색 단계. 노랑(#ffe44d)은 형광펜과 AI 표시 두 곳에만 쓴다.
2. 모든 구획은 1px 헤어라인(#e3e3e0)으로 나눈다. 그림자는 카드에만 아주 옅게.
3. 한 줄(또는 한 묶음)에 검정 강조 카드는 하나만. 글 목록의 첫 카드와 '오늘의 글' 첫 카드.
4. 영문 제목은 Hanken Grotesk, 한글과 본문은 Pretendard. 자간은 제목 -0.03em, 본문 -0.01em, `word-break: keep-all`.
5. 누르는 것은 높이 44px 이상. 공개/나만보기는 색이 아니라 선(실선/점선)과 글자로 구분한다. 오류는 색과 문구를 함께.

## 글꼴·크기
- display: Hanken Grotesk 500/700/800 (Google Fonts) → 없으면 Pretendard.
- body: Pretendard Variable, 15px, 줄 간격 1.7. 글 상세 본문은 16.5px, 줄 간격 1.9.
- 제목: 첫 화면 h1 clamp(26px,4.4vw,46px) 800 · 글 상세 h1 clamp(26px,4vw,38px) 800 · 글 카드 제목 17px 800.
- 라벨·메타: 12~13px, display 글꼴, 700(라벨)/500(메타).

## 모양
- 카드 모서리 14px, 입력칸 10px, 버튼·칩 999px(알약). 간격은 4·8·12·16·24·32·48px.
- 카드 그림자 `0 6px 18px rgba(0,0,0,.05)`. 호버 시 위로 2~3px.
- 썸네일 이미지는 흑백(`grayscale(1)`), 비율 4:3.
- 형광펜 CSS: `background: linear-gradient(transparent 14%, #d6d6d2 14%, #d6d6d2 94%, transparent 94%)`

## 화면 구조 (v2.0)
- 상단 바 56px, 흰 배경 + 아래 헤어라인. 로고 "AIPM 복습 노트".
- 첫 화면: 날짜 칸 | 오늘의 한 줄 → 세로로 쓴 큰 "AIPM" | (라벨 | 본문) 행 2개(과정 기록, 이 블로그 표).
- 목록 머리: 검정 상단선 + 밑줄형 탭(전체·공개·나만보기) + 검색칸(알약).
- 글 카드: 4열(900px 이하 2열, 620px 이하 1열). 첫 카드만 검정.
- 푸터: 큰 "AIPM" 워드마크.
- 반응형 경계: 900px, 620px. 가로 넘침이 없어야 한다(ui-check UI-15).

## 사진 갤러리 (v2.1, 결정 #39~#41)
- 격자 `pgrid`: 4열(900px 이하 3열, 620px 이하 2열), 정사각 타일 `ptile`(모서리 14px, 헤어라인 테두리, 옅은 그림자), 사진은 **색 그대로**. 글 카드 썸네일만 흑백.
- 글 아래 갤러리 `gallery`: 검정 상단선 + "사진 N장" 머리 + 3열(모바일 2열).
- 목록 '사진' 탭: 모든 글의 사진을 모아 보며 아래에 제목·날짜 캡션. 나만보기 글 사진은 로그인한 관리자에게만.
- 크게 보기 `lb`: 검정 97% 배경 전체 화면, 사진은 화면 안에 맞춤, 닫기·이전·다음 버튼 44px 이상, ←/→/Esc 키, Tab 키는 창 안에서만 이동.
- 올리기: 최대 8장, 가로 800px, JPEG 0.7, 글 전체 950KB 이하. 미리보기 타일에 ✕(36px).

## 컴포넌트 (클래스 이름은 v1.5와 동일)
`btn`(.primary/.danger) `chip` `badge`(.pub/.priv) `aib`(AI 칩, .on=노랑) `tag` `mark` `post` `note` `card` `tabs` `aicard`(AI 제안 카드) `toast` `fab`.
AI 제안 카드: 검정 1px 테두리, 실패는 점선, 반영 후는 옅은 테두리. 제목 후보는 알약 라디오(선택하면 검정 바탕).

## 글쓰기 편집기
- 도구 막대: 굵게 · 기울임 · 밑줄 · 취소선 · 글씨 크기 · 글자색 · 소제목 · 인용 · 목록 · 서식 지움 · 이미지. 배경 #f6f6f3, 버튼 높이 40px 이상(모바일에서도 모두 화면 안).
- 글씨 크기: 작게(0.85배) · 보통 · 크게(1.35배) · 아주 크게(1.8배).
- 글자색 7가지(글 본문 안에서 쓰는 색, 화면 디자인 색과 별개): 검정 #1b1b1b · 빨강 #d93025 · 주황 #e8710a · 초록 #188038 · 파랑 #1a73e8 · 보라 #7b3fe4 · 회색 #7a7a7a. 새 색은 결정 문서에 먼저 적는다.
- 이미지: 가로 900px 이하 JPEG, 둥근 모서리 10px, 화면 폭을 넘지 않음. 글 한 편은 합쳐서 약 1MB 이하.
- 본문 표시: 허용한 태그만 남긴다(`CLAUDE.md` 3-2).

## 접근성
글자와 배경 대비 4.5:1 이상(가장 낮은 조합 mute #74746f / paper #fff 약 4.7). 포커스는 2px 검정 윤곽선. 움직임 줄이기 설정이면 전환 효과 끔.

## 알려진 한계 (정직하게)
- 색 대비 수치는 계산값이고 도구로 재검증하지 않았다.
- 폰트 파일(`fonts/PretendardVariable.woff2`)이 없으면 CDN을 쓴다. Hanken Grotesk는 Google Fonts 연결이 필요(실패해도 Pretendard로 대체).
- 글 카드 썸네일의 흑백 처리는 대표 이미지 색감을 지운다(의도된 선택이지만 사용자 의견은 아직 못 받음). 갤러리 사진은 컬러.
- 사진 용량은 합성 테스트 사진으로만 확인했다. 실제 휴대폰 사진(수 MB)을 올렸을 때 800px로 줄어든 크기는 배포 후 확인이 필요하다.
