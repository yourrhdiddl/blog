# 실패 로그 · 깃헙 푸시 403 (2026.11.17)

- **증상:** `git push`가 403으로 거부됨. `gh` 명령도 "연결된 GitHub 계정 없음".
- **원인:** 작업 세션이 허용한 저장소 목록에 `yourrhdiddl/blog`가 없어서 프록시가 인증을 넣어주지 않음.
- **해결(임시):** 로그인된 GitHub 웹 화면에서 편집기로 붙여넣고 Commit. 올린 뒤 파일 해시를 로컬과 비교해 같은지 확인.
- **한계:** 커밋 메시지가 기본 문구가 되고, 파일이 많으면 번거롭다.
- **재발 방지:** 세션 설정에서 이 저장소를 허용 목록(sources)에 추가하면 `git push`가 된다.
