## 4. 읽는 법과 한계 (비판적으로)
- Claude 쪽 수치가 높아 보이지만, 판정을 한 주체가 Claude였습니다. 같은 계열 모델이 제안과 판정을 모두 하면 후하게 나올 수 있어 과대평가 가능성이 있습니다. 하늘의 직접 판정으로 확대 측정하는 것이 다음 할 일입니다.
- 표본이 12편이고 모두 길이와 형식이 비슷한 일상·업무 글이라, 실제 사용자 글 전반으로 일반화할 수 없습니다.
- 제목은 후보 중 첫 번째를 그대로 반영해 '쓸 만한지'만 봤고, 수정 반영(edited)은 따로 세지 않았습니다. 일부 후보에는 본문에 없는 해석(예: '초보', '비용 절감')이 섞여 있었습니다.
- 하루 AI 호출 상한(기본 20건)에 걸리면 제안이 '보류'됩니다. 2차 측정은 상한을 일시적으로 40으로 올려 진행했고, 측정 후 원래 값으로 되돌리는 절차를 진행 중입니다.
- 테스트 글은 모두 휴지통으로 보냈고 평가용 안내 글은 그대로 두었습니다.
