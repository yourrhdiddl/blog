# Firestore 보안 규칙 참고 (2026.11.24) · 미확인 상태

> **이 문서의 목적:** AI 제안 반영(updateDoc)에 필요한 Firestore 보안 규칙의 참고 예시를 적고, 실제 규칙을 확인·적용하는 순서를 안내한다.

> 이 저장소에는 실제 규칙 파일이 없다. 규칙은 Firebase 콘솔에만 있어 **현재 적용된 내용을 확인하지 못했다**(결정 #30).
> 아래는 AI 제안 반영(`updateDoc`)에 필요한 부분의 참고 예시다. 콘솔의 현재 규칙을 먼저 읽고, 이미 `isAdmin()`이 있으면 `update` 줄만 맞춰 넣는다.

```
match /posts/{id} {
  // 관리자만 수정, 그리고 AI 제안 반영에 쓰는 필드만 바꿀 수 있다
  allow update: if isAdmin()
    && request.resource.data.diff(resource.data).affectedKeys()
       .hasOnly(['title','summary','tags','aiStatus','aiFeedback','aiAppliedAt']);
}
```

- 배치(`scripts/gen-ai.mjs`)는 서비스 계정(Admin SDK)으로 쓰므로 규칙을 거치지 않는다. `meta/aiUsage` 문서는 클라이언트 접근이 필요 없어 `allow read, write: if false;`로 둔다.
- 적용 뒤 확인: 관리자 로그인 상태에서 제안을 반영해 성공하는지, 시크릿 창(비로그인)에서 수정이 거부되는지.
